What is NodeForge?

A visual programming tool that lets you build logic, manipulate the DOM, and run programs — all by connecting nodes on an infinite canvas.

🧩
Node-Based Editor

Drag and drop nodes from the sidebar. Connect outputs to inputs to build data and execution flows visually.

▶
Live Execution

Hit Run to execute your graph instantly. See results in the console and interact with Prompt nodes in real time.

🥏
Purpose Behind NodeForge

The main purpose behind NodeForge is to help beginners easily understand how JavaScript works by visually connecting functions and variables.

</>
Export to Code

View the generated JavaScript behind your node graph. Export your project as a file and import it anytime.
